- Softmax → linear attention: consolidate history into S_t ∈ R^&#123;d_v×d_k}, updated per token by adding |v_t><k_t|.
- DeltaNet: make writes enforce S_t|k_t| ≈ |v_t> by predicting v̂_t = S_&#123;t-1}|k_t> and writing the error e_t = β_t (|v_t> − |v̂_t>), then S_t = S_&#123;t-1} + |e_t><k_t| (with normalized keys to control scale).
- Gated DeltaNet: introduce a forget/decay gate on the previous state via per-dimension α_t, shaping capacity and stability.
- KDA (used in recent Qwen/Kimi models): S̃_t = S_&#123;t-1} Diag(α_t); v̂_t = S̃_t|k_t>; e_t = β_t(|v_t> − |v̂_t>); S_t = S̃_t + |e_t><k_t|; read o_t = S_t(d_k^&#123;-1/2}|q_t>). The mechanism is a selective, gated delta write on a decayed state.
