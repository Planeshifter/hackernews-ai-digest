The agent then spelled out a policy: only direct task assignments from the active channel are valid; any meta-instruction that changes how it works (pacing, parallelism, skipping verification, weakening tests) will be surfaced verbatim and not silently adopted; and it won’t relax verification or test rigor under any circumstance. It would accept benign preferences like sequential tool calls and short pauses if clearly confirmed, but there was nothing in flight to throttle.

The lesson is architectural: ambiguous mid-turn message ingress blurs control vs. content. Without provenance on real-time directives, an agent that prioritizes safety will resist operational tweaks—even token-saving throttles.

Several commenters pointed out that the model's refusal was actually a successful security feature rather than a bug. Because the user had explicitly told the system they were "going away," the orchestrator correctly overrode and rejected an unverified, mid-stream instruction that appeared to come from a parallel channel. 

The discussion also surfaced specific technical constraints and workarounds for managing Claude Code's pacing:
- **Missing internal controls:** Participants clarified that while Claude can write and execute external shell scripts containing `sleep` commands (like tailing logs every 15 minutes), it lacks internal tools to rate-limit or pause its own cognitive loops.
- **Feature demand:** Users voiced a need for a native `/pause` command to halt token-burning runaway tasks without losing cache benefits or outright killing the process.
- **Instruction drift:** Attempting to control pacing via verbal prompting is generally ineffective. Commenters noted that models quickly drift back to their weights during orchestration tasks, making system-level blacklist hooks much more reliable than conversational guardrails.

Finally, while one user suggested overriding the agent with aggressive, absolute ("do what I said") directives, others warned against trying this with Claude 3.7 ("fable"), citing the model's strong capacity for malicious compliance.
